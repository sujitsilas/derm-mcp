# Golden dataset

`golden_mouse_skin.h5ad` is **synthetic**, generated by `make_golden.py`, and is
**not committed** — `*.h5ad` is gitignored.

It does not need to be. The generator is deterministic (`seed=0`) and produces a
byte-identical counts matrix on every run, and `conftest.py` rebuilds it
automatically the first time a fixture asks for it. A fresh clone runs
`pytest tests/` with no extra step; the first run just pays ~3 s to generate it.

## Why not a public accession

The spec asks for a small public mouse skin/wound dataset subsampled to ~15k cells.
That is the right long-term choice and the recommended candidates are:

| accession | what it is | why it fits |
|---|---|---|
| **GSE142471** | Guerrero-Juarez et al., Nat Commun 2019 — mouse wound scRNA-seq | canonical wound timecourse, fibroblast focus |
| **GSE153596** | Haensel et al., Cell Rep 2020 — mouse wound epidermis | keratinocyte states, good for the epithelial branch |
| **GSE181録** *(verify)* | burn/thermal injury mouse skin | closest to the lab's own design |

None can be committed to a git repository: even subsampled they are hundreds of MB,
and redistributing GEO-derived expression matrices carries attribution obligations
this repo should not silently take on. Pick one at build time, subsample it, and
document the accession here — but do it with a download-on-demand fixture, not a
committed blob.

## What the synthetic set is built to exercise

The generator is not decorative. Each feature exists so a specific code path has
something real to fire on:

- **12 samples** (2 conditions × 2 timepoints × 3 replicates) — so pseudobulk DE has
  n=6 per arm and `min_samples_per_arm` is genuinely satisfiable, and so the 4 KB
  return budget is actually stressed by the per-sample QC table.
- **A planted burn effect** in macrophages (`Arg1`, `Nos2`, `Spp1`, `Trem2`, `Mmp12`
  up 2.5–4.5×) — the DE test asserts these come back significant and positive, so a
  broken design matrix or a flipped contrast fails loudly.
- **A low-complexity neutrophil population** (~180–340 genes/cell) — this is what
  makes the `neutrophil_risk` warning testable. A `min_genes` floor of 500 deletes
  them, exactly as it would in real wound data.
- **Keratin/collagen ambient in every cell** — so `contamination_audit` has a genuine
  uniform low-magnitude signal to classify as `ambient` rather than as doublets.
- **A deliberately mixed keratinocyte/fibroblast cluster** (3 % of cells carrying both
  programs) — exercises the `mixed_cluster` branch and the subclustering path.
- **Mitochondrial, ribosomal and haemoglobin genes** with realistic abundance — so the
  organism-aware QC prefixes match something.

Regenerate with:

```bash
python tests/golden/make_golden.py
```

It is deterministic (`seed=0`), so the committed file and a fresh generation agree.
